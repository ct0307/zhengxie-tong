实验7：基于 Hooks 的 React 课程管理

一、实验名称

基于 Hooks 的 React 课程管理页面升级实验

二、实验目标

在实验5"React 课程管理页面"的基础上，进一步掌握 React Hooks 的实际应用，能够使用 Hooks 对已有项目进行功能增强与结构优化。通过本实验，达到以下目标：

  1. 理解并掌握 useEffect 的基本用法，能够处理副作用逻辑（DOM 操作、数据持久化）。
  2. 理解并掌握 useRef 的使用，能够完成输入框聚焦等 DOM 操作。
  3. 理解并掌握 useMemo 的使用，能够对列表过滤结果和统计数据进行缓存优化。
  4. 理解并掌握 useCallback 的使用，能够优化事件函数传递并减少子组件重渲染。
  5. 理解自定义 Hook 的封装思想，提升逻辑复用能力（useLocalStorage、useDebounce）。
  6. 在原有课程管理页面基础上，实现搜索防抖、数据持久化、统计显示、分类标签等增强功能。
  7. 提高函数组件开发能力，形成"逻辑用 Hook 封装，UI 用组件展示"的开发思路。

三、实验背景

实验5已经完成了一个基础的课程管理页面，主要包含以下功能：

  • 显示课程列表
  • 展示课程名称与课程简介
  • 新增课程
  • 删除课程
  • 学习按钮交互
  • 列表渲染（map）
  • props 传值
  • state 状态管理（useState）
  • 输入校验
  • 页面基础样式

在此基础上，本实验将结合 Hooks 课程内容，对该页面进行功能扩展和代码优化，使项目更贴近现代 React 开发模式。Hooks 章节重点包含 useEffect、useRef、useMemo、useCallback 和自定义 Hook，本实验将围绕这些内容进行综合实践，实现搜索防抖、数据持久化、输入框自动聚焦、列表缓存优化等功能。

六、实验设计思路

Hook 对应功能设计

  • useState：管理课程列表、输入内容、搜索关键词、分类选择
  • useEffect：页面首次加载时自动聚焦输入框；配合自定义 Hook 实现 localStorage 数据同步
  • useRef：获取课程名称输入框 DOM 引用，新增课程后自动调用 focus()
  • useMemo：缓存搜索过滤后的课程列表；缓存课程数量统计数据
  • useCallback：缓存 handleLearn、handleAddCourse、handleDeleteCourse 等事件处理函数，避免子组件不必要的重渲染
  • 自定义 Hook：useLocalStorage 封装 localStorage 读写逻辑；useDebounce 封装搜索防抖逻辑

1. 课程新增功能

用户在输入框中输入课程名称（必填）、简介（选填）和分类后，点击"添加课程"按钮，即可将课程加入课程列表。若输入为空，则给出提示，不允许添加。新增成功后通过 useRef 使输入框自动聚焦。

2. 课程删除功能

每条课程卡片中都有"删除"按钮，点击后可移除该课程。删除后统计数据和 localStorage 自动同步更新。

3. 学习按钮交互

每条课程卡片中都有"学习"按钮，点击后弹出提示，例如"正在学习 React Hooks"。该函数通过 useCallback 缓存，避免子组件不必要的重渲染。

4. 搜索功能

用户输入关键词后，通过自定义 Hook useDebounce 实现 300ms 防抖延迟，根据课程名称和简介进行实时筛选。搜索结果数量实时显示。

5. 本地存储功能

通过自定义 Hook useLocalStorage 封装 localStorage 读写逻辑。页面刷新后，课程数据从 localStorage 中重新读取，不会丢失。

6. 输入框自动聚焦

每次新增课程后，通过 useRef 获取输入框 DOM 引用并调用 focus() 方法，使课程名称输入框自动获得焦点，方便继续输入。页面首次加载时也会自动聚焦。

7. 列表缓存优化

当课程列表较多时，通过 useMemo 缓存筛选结果和统计数据，减少不必要的重复计算。仅在课程列表或搜索关键词变化时重新计算。

8. 回调函数优化

通过 useCallback 缓存传递给子组件的函数（handleLearn、handleAddCourse、handleDeleteCourse），减少由于函数引用变化导致的子组件重复渲染。配合 React.memo 使用，实现组件级渲染优化。

七、关键 Hooks 使用分析

1. useEffect 的作用

本实验中 useEffect 主要完成以下任务：

  • 页面首次加载时，自动将课程名称输入框聚焦，提升用户体验
  • 在自定义 Hook useLocalStorage 中监听状态变化，自动同步保存到 localStorage
  • 在自定义 Hook useDebounce 中设置定时器实现搜索防抖

这体现了 useEffect 处理副作用的核心作用。副作用包括 DOM 操作、数据持久化、定时器等，本实验中的输入框聚焦、localStorage 同步和防抖定时器都属于典型的副作用场景。

2. useRef 的作用

useRef 用于获取课程名称输入框的 DOM 引用，在新增课程成功后调用 titleInputRef.current.focus() 实现自动聚焦。useRef 不会触发重新渲染，适合保存 DOM 节点引用或跨渲染周期保持的可变值。

3. useMemo 的作用

课程搜索时，需要根据关键词对课程列表进行过滤。若每次渲染都重新计算过滤结果和统计数据，可能造成性能浪费。因此使用 useMemo 对 filteredCourses 和 stats 进行缓存，仅在课程列表或搜索关键词变化时重新计算。这符合 Hooks 课程中关于 useMemo 适用于列表过滤、排序和复杂计算的最佳实践。

4. useCallback 的作用

handleLearn、handleAddCourse、handleDeleteCourse 作为回调函数传入子组件（CourseList、CourseCard）。如果每次渲染都重新创建函数引用，会导致子组件的 React.memo 浅比较失效，引发不必要的重渲染。通过 useCallback 缓存函数引用，并配合 React.memo 优化子组件，有效减少了不必要的渲染开销。

5. 自定义 Hook 的作用

本实验封装了两个自定义 Hook：

  • useLocalStorage：将状态管理与 localStorage 持久化封装在一起，初始化时读取已保存的数据，状态变化时自动写入，实现数据持久化逻辑的可复用。
  • useDebounce：接收输入值和延迟时间，返回防抖后的值。在搜索功能中应用，避免用户每输入一个字符就触发过滤计算，提升输入流畅度。

自定义 Hook 遵循 "逻辑复用、UI 分离" 的开发思路，是现代 React 开发的重要模式。
